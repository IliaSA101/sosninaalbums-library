# Sosnina Albums — библиотека наборов

Наборы оформления для [Sosnina Albums](https://github.com/IliaSA101/sosninaalbums): фоны, стикеры
и готовые развороты. Программа (0.17 и новее) находит их сама — окно «Наборы библиотеки» →
«Обновить библиотеку»; архив из раздела Releases можно поставить и вручную: «Добавить из файла».

Всё содержимое нарисовано процедурно генератором программы и передано в общественное достояние
(CC0 1.0): его можно использовать в любых альбомах, в том числе коммерческих, без указания
авторства.

## Наборы

| Набор | Что внутри | Размер |
| --- | --- | --- |
| **Свадьба — айвори и золото** (`wedding-ivory-gold`) | 5 фонов (золотая пыль, ар-деко, шампань, лён, сияние на разворот), 5 золотых стикеров (венок, уголок, разделитель, искры, рамка для монограммы), 5 разворотов | 12,6 МБ |
| **Свадьба — шалфей** (`wedding-sage`) | 5 фонов (туман, акварель, листья, лён, свет на разворот), 5 стикеров (эвкалипт, полувенок, веточка, уголок, ромашки), 4 разворота | 9,5 МБ |
| **Свадьба — пыльная роза** (`wedding-dusty-rose`) | 5 фонов (акварель, румянец, лепестки, мазки, свечение на разворот), 5 стикеров (роза, букет, гирлянда, лепестки, сердце), 4 разворота | 4,1 МБ |

Фоны — PNG 3602×3602 (страница 30,5×30,5 см при 300 dpi) и 7205×3602 (на весь разворот); это
фактуры без рамок, поэтому подходят к любому формату листа. Стикеры — PNG с прозрачностью,
до 2400 px по стороне.

## Как устроен репозиторий

- `catalog.json` — список наборов для программы: конверт `{sig, body}`, подпись ed25519 по байтам
  `body`, номер выпуска каталога `seq` растёт с каждой публикацией. Программа принимает только
  каталог с подписью ключа проекта; адрес архива — только Releases этого репозитория, архив
  сверяется по sha256 из каталога.
- Релиз `<id>-v<версия>` — архив `<id>-<версия>.zip` (манифест, картинки, шаблоны разворотов,
  `LICENSE.txt`).

Пределы набора: архив ≤ 300 МБ, предметов ≤ 1000, фон ≤ 60 МБ и ≤ 100 Мп, стикер ≤ 30 МБ и
≤ 4096 px по стороне, шаблон разворота ≤ 256 КБ; только PNG и JPEG (SVG не принимается).
